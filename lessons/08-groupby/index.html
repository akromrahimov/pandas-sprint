02 · Теория

groupby = разложить по коробкам и посчитать каждую

Простыми словами

Представь, что на столе куча конфет разного цвета. Мама просит: «Скажи, сколько красных, сколько зелёных, сколько жёлтых». Ты делаешь три шага: 1) раскладываешь конфеты по коробкам — каждый цвет в свою; 2) считаешь каждую коробку отдельно; 3) пишешь ответ на одном листочке: «красных 5, зелёных 3, жёлтых 7».

  • groupby("city") — шаг 1: «разложи строки по коробкам, на каждой коробке написан город». Сам по себе он ничего не считает — только раскладывает.
  • Ключ группировки — то, что написано на коробке (здесь город). Одинаковая надпись = одна коробка. «Ташкент» и « Ташкент» — две разные коробки, поэтому сначала чистка (урок 6).
  • size() — «сколько строк в коробке» (COUNT(*)). count() — «сколько заполненных ячеек в колонке» (COUNT(amount)): пустые NaN не считает.
  • sum(), mean(), median() — шаг 2 для каждой коробки: сумма, среднее, середина.
  • agg(...) — «посчитай сразу несколько вещей».
  • Результат — шаг 3: одна строка на каждую коробку. Названия коробок становятся Index (бирками строк) результата.

Учёные называют это split → apply → combine: разделить → применить расчёт → собрать обратно. Главная мысль дня: сначала чистые ключи, потом groupby, потом проверка: сумма по группам = итог по всей таблице.

03 · Теория

Восемь приёмов: посчитать по группам правильно

Как читать код
  • df.groupby("city") — «разложи строки df по коробкам с одинаковым city». Это ещё не ответ: если напечатать, увидишь непонятное <DataFrameGroupBy object>. Нужен шаг «посчитай».
  • df.groupby("city")["amount"] — квадратные скобки после groupby = «в каждой коробке смотрим только на колонку amount».
  • .agg(["sum", "mean"]) — список в квадратных скобках = «посчитай сумму И среднее». Получится таблица: столбец на каждую функцию.
  • .agg(orders=("order_id", "size")) — named aggregation: слева от = — имя новой колонки (как AS orders), справа в круглых скобках пара: (какая колонка, какая функция).
  • mask.groupby(df["city"]).mean() — маска True/False, разложенная по городам. mean() от True/False = доля True в каждой коробке.
  • groupby(["city", "channel"], as_index=False) — список = два ключа (коробка «ташкент + app», «ташкент + web»…). as_index=False — ключи остаются обычными колонками, а не бирками строк.
  • Скобки вокруг длинной цепочки ( … ) позволяют переносить строки: каждый шаг на своей строке.

Каждый вывод ниже получен реальным запуском pandas 3.0 на файле Yetkaz. Карточки идут подряд: в карточке 2 мы почистили city, дальше работаем с чистым.

1. Сырой groupby — коробок больше, чем городов.
import pandas as pd

df = pd.read_csv("yetkaz_orders.csv")
df.groupby("city").size()
city Ташкент 75 Бухара 211 Наманган 180 Самарканд 298 Ташкент 700 самарканд 29 ташкент 107 dtype: int64

Простыми словами: городов 4, а коробок 7. « Ташкент» (75), «Ташкент» (700) и «ташкент» (107) — для pandas три разных города. Excel Ойбека сделал то же самое: показал Ташкенту 700 заказов вместо настоящих 882.

2. Сначала чистка ключа, потом size().
df["city"] = df["city"].str.strip().str.lower()
df.groupby("city").size().sort_values(ascending=False)
city ташкент 882 самарканд 327 бухара 211 наманган 180 dtype: int64

Простыми словами: после strip + lower осталось 4 коробки. В Ташкенте 882 заказа — в 2.7 раза больше, чем в Самарканде (327). Проверка: 882 + 327 + 211 + 180 = 1 600 — все строки на месте.

3. count() не считает пустые ячейки.
print(df.groupby("city")["amount"].count())
print(df["amount"].isna().sum())
city бухара 204 наманган 167 самарканд 315 ташкент 835 Name: amount, dtype: int64 79

Простыми словами: count по amount в Ташкенте — 835, а заказов 882: у 47 заказов касса не записала сумму. Всего пустых сумм 79. Если «число заказов» считать через count(amount), ты потеряешь эти заказы. Число строк — это size().

4. Несколько функций сразу — agg со списком.
df.groupby("city")["amount"].agg(["sum", "mean", "median"]).round(0)
sum mean median city бухара 15307000.0 75034.0 66000.0 наманган 12476000.0 74707.0 64000.0 самарканд 24167000.0 76721.0 69000.0 ташкент 75357000.0 90248.0 80000.0

Простыми словами: для каждого города — сумма, среднее и медиана суммы заказа. Средний чек в Ташкенте 90 248 сум, в Самарканде 76 721. Медиана везде ниже среднего: несколько дорогих заказов (суши за 399 000) тянут среднее вверх.

5. Named aggregation: свои названия колонок.
(df.groupby("city")
   .agg(orders=("order_id", "size"),
        avg_check=("amount", "mean"),
        avg_min=("delivery_min", "mean"))
   .round(1)
   .sort_values("orders", ascending=False))
orders avg_check avg_min city ташкент 882 90247.9 52.2 самарканд 327 76720.6 41.0 бухара 211 75034.3 39.0 наманган 180 74706.6 37.3

Простыми словами: мы сами дали колонкам понятные имена: orders, avg_check, avg_min. В Ташкенте доставка в среднем 52.2 минуты, в остальных городах 37–41. Заметь: ("order_id", "size") — число строк, неважно, какую колонку взять.

6. Доля в каждой группе — mean от маски.
cancel = df["status"] == "cancelled"
cancel.groupby(df["city"]).mean().mul(100).round(1)
city бухара 5.7 наманган 6.7 самарканд 7.3 ташкент 13.8 Name: status, dtype: float64

Простыми словами: маска говорит про каждый заказ «отменён? да/нет». Разложили по городам и взяли mean — это доля «да» в каждой коробке. В Ташкенте отменяют 13.8% заказов, в Бухаре — 5.7%. «В среднем 10.6%» у Ойбека прятало эту разницу.

7. Два ключа и as_index=False.
(df.groupby(["city", "channel"], as_index=False)["amount"]
   .mean().round(0).head(6))
city channel amount 0 бухара app 74162.0 1 бухара telegram 69349.0 2 бухара web 86581.0 3 наманган app 78564.0 4 наманган telegram 69037.0 5 наманган web 65667.0

Простыми словами: коробки теперь двойные: «бухара + app», «бухара + telegram»… Благодаря as_index=False город и канал — обычные колонки, а слева простой номер строки. Такую таблицу легко фильтровать, сортировать и отдавать в Excel.

8. Уникальные в группе — COUNT(DISTINCT).
df.groupby("city")[["customer_id", "courier_id"]].nunique()
customer_id courier_id city бухара 177 12 наманган 162 12 самарканд 248 12 ташкент 459 12

Простыми словами: клиентов в Ташкенте 459, а курьеров — 12, как и везде. 882 заказа на 12 курьеров — это 73.5 заказа на курьера, в Самарканде — 27.2. Вот почему в Ташкенте доставка дольше.

История про карманные деньги: почему «среднее средних» врёт

В классе 5 детей. В группе А двое: у Али 10, у Вали 20. В группе Б трое: Сара 30, Лола 40, Тимур 50. Сумма в группе А = 30, в группе Б = 120. Среднее А = 15, среднее Б = 40.

группа А: 10, 20 → среднее 15группа Б: 30, 40, 50 → среднее 40
kids = pd.DataFrame({"group": ["А", "А", "Б", "Б", "Б"],
                     "money": [10, 20, 30, 40, 50]})
kids.groupby("group")["money"].agg(["sum", "mean"])
sum mean group А 30 15.0 Б 120 40.0

«Среднее средних» = (15 + 40) / 2 = 27.5. А настоящее среднее по классу = 150 / 5 = 30. Разница — потому что в группе Б детей больше. Правило: общее среднее считай по всей таблице, а не по готовым средним групп.

Бонус. Та же ловушка на заказах Yetkaz.
by_city = df.groupby("city")["amount"].mean()
print(round(by_city.mean()), round(df["amount"].mean()))
79177 83700

Простыми словами: среднее из четырёх средних чеков городов — 79 177, а настоящий средний чек всех заказов — 83 700. Маленькие города получили такой же «голос», как Ташкент с 835 суммами. Ошибка в 4 500 сум на чек — и ты бы её не заметил.

Правило аналитика. После groupby сверь итог: сумма size() по группам = len(df), сумма revenue по группам = общая выручка. Не сходится — где-то потерялись строки (грязный ключ или NaN в ключе).
04 · Ловушки

Пять ошибок, на которых спотыкается большинство

1

Грязный ключ дробит группы

df.groupby("city").size() # 7 групп: «Ташкент», « Ташкент», «ташкент»…
df["city"] = df["city"].str.strip().str.lower() # 4 группы

Перед groupby посмотри value_counts() ключа. Почти одинаковые значения — сначала чистка.

2

count() вместо size()

df.groupby("city")["amount"].count() # ташкент 835 — потеряны 47 заказов
df.groupby("city").size() # ташкент 882

count считает заполненные ячейки, size — строки. «Сколько заказов» = size.

3

Доля от всех вместо доли в группе

df[df["status"] == "cancelled"].groupby("city").size() / len(df) * 100 # ташкент 7.6
(df["status"] == "cancelled").groupby(df["city"]).mean() * 100 # ташкент 13.8

Первый вариант делит на ВСЕ 1 600 заказов. Вопрос «какая доля отмен в Ташкенте» — делить на заказы Ташкента. mean() от маски делает это сам.

4

mean() по всей таблице с текстом

df.groupby("city").mean() # TypeError: dtype 'str' does not support operation 'mean'
df.groupby("city")["amount"].mean()

В pandas 3.0 текстовые колонки не усредняются. Выбирай колонку в квадратных скобках.

5

Среднее средних

df.groupby("city")["amount"].mean().mean() # 79 177
df["amount"].mean() # 83 700

Группы разного размера. Общее среднее — только по исходным строкам.

Шпаргалка урока: 8 строк, которые надо помнить

  1. df["city"] = df["city"].str.strip().str.lower() — сначала чистый ключ
  2. df.groupby("city").size() — COUNT(*)
  3. df.groupby("city")["amount"].count() — COUNT(amount), без NaN
  4. df.groupby("city")["amount"].agg(["sum", "mean", "median"]) — несколько функций
  5. df.groupby("city").agg(orders=("order_id", "size"), avg_check=("amount", "mean")) — AS
  6. (df["status"] == "cancelled").groupby(df["city"]).mean() * 100 — доля в группе, %
  7. df.groupby(["city", "channel"], as_index=False)["amount"].mean() — два ключа
  8. df.groupby("city")["customer_id"].nunique() — COUNT(DISTINCT)
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. df.groupby("city") без функции после него — что получится?

groupby только раскладывает. Ответ появляется после size(), sum(), mean() или agg().

2. В Ташкенте 882 заказа, а groupby("city")["amount"].count() показывает 835. Почему?

size() = строки (COUNT(*)), count() = заполненные (COUNT(amount)).

3. Как получить долю отменённых заказов внутри каждого города?

mean от True/False в каждой коробке = доля True в этой коробке. Первый вариант делит на все 1 600 заказов (ташкент 7.6 вместо 13.8).

4. Средние чеки городов: 90 248, 76 721, 75 034, 74 707. Их среднее 79 177. Общий средний чек?

Среднее средних даёт маленьким городам такой же вес, как Ташкенту. Общее среднее — df["amount"].mean().

5. Что делает as_index=False в groupby(["city", "channel"], as_index=False)?

Получается плоская таблица, как результат SQL-запроса. То же даёт .reset_index() после расчёта.
