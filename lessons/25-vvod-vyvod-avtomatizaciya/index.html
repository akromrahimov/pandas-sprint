Ввод-вывод и автоматизация отчёта

Данные приходят из разных мест: CSV, Excel от бухгалтерии, база данных. А результат нужно отдать так, как удобно руководителю, — чаще всего в Excel с несколькими листами. Сегодня учимся читать и писать Excel, делать SQL-запросы прямо из pandas и превращать отчёт в функцию, которая сама собирает файл каждую неделю.

02 · Теория

Читать правильно: колонки, типы, даты

Простыми словами

read_csv — как сканер документов: у него много настроек, и правильные настройки экономят часы ручной работы.

  • usecols=[…] — читать только нужные колонки.
  • parse_dates=["order_date"] — сразу превратить колонку в даты.
  • sep=";", decimal="," — для файлов из «русского» Excel, где разделитель — точка с запятой, а дробная часть — через запятую.
  • encoding="cp1251" — если вместо русских букв «кракозябры» (старые файлы Windows).
1. Только нужное.
small = pd.read_csv("yetkaz_orders.csv", usecols=["order_id", "order_date", "city", "amount", "status"],
                    parse_dates=["order_date"])
print(small.shape)
small.dtypes
(1600, 5) order_id int64 order_date datetime64[us] city str amount float64 status str dtype: object

Простыми словами: из 12 колонок взяли 5, дата сразу стала датой. Меньше памяти и меньше путаницы.

03 · Теория

Excel с листами и SQL-запросы из pandas

Как читать код
  • with pd.ExcelWriter("файл.xlsx") as w: — «открой Excel-файл для записи». Внутри блока каждая таблица пишется на свой лист: table.to_excel(w, sheet_name="лист"). Когда блок заканчивается, файл сохраняется.
  • pd.read_excel("файл.xlsx", sheet_name="лист") — прочитать нужный лист. pd.ExcelFile(f).sheet_names — список листов.
  • sqlite3 — маленькая база данных прямо в Python. df.to_sql("orders", con) кладёт таблицу в базу, pd.read_sql("SELECT …", con) выполняет запрос и возвращает DataFrame.
  • to_csv(f, sep=";", decimal=",", encoding="utf-8-sig") — CSV для русского Excel: колонки через точку с запятой, дроби через запятую, а utf-8-sig подсказывает Excel, что в файле русские буквы.
2. Отчёт в Excel с двумя листами.
clean = df.assign(city=df["city"].str.strip().str.capitalize())
by_city = clean.groupby("city").agg(orders=("order_id", "count"), revenue=("amount", "sum"))
with pd.ExcelWriter("report.xlsx") as w:
    by_city.to_excel(w, sheet_name="города")
    clean.head(50).to_excel(w, sheet_name="примеры", index=False)
pd.ExcelFile("report.xlsx").sheet_names
['города', 'примеры']

Простыми словами: один файл, два листа. Бухгалтерия откроет его обычным Excel.

3. Прочитать лист обратно. Так проверяют, что файл записался правильно.
back = pd.read_excel("report.xlsx", sheet_name="города")
back.head(3)

Простыми словами: sheet_name говорит, какой лист открыть. Колонка city вернулась обычной колонкой: при записи индекс (города) сохранился в файл первым столбцом.

4. SQL-запрос к таблице.
con = sqlite3.connect(":memory:")
clean.to_sql("orders", con, index=False)
pd.read_sql("SELECT status, COUNT(*) AS n FROM orders GROUP BY status", con)
status n 0 cancelled 170 1 delivered 1430

Простыми словами: ":memory:" — база живёт только пока работает код. Настоящую базу компании подключают так же, только вместо ":memory:" — адрес сервера.

SQL для тех, кто его не знает: 5 слов

SQL — язык запросов к базам данных. В компаниях данные часто лежат в базе, поэтому аналитику полезно читать простые запросы. Один и тот же вопрос на SQL и в pandas:

    SELECT city, COUNT(*) AS n
    FROM orders
    WHERE status = 'cancelled'

    ORDER BY n DESC
""", con)

print(sql)

Простыми словами: ответы одинаковые. Таблица orders уже лежит в базе con из примера 4. Текст в SQL берут в одинарные кавычки: 'cancelled'.

6. Отчёт как функция. Одна функция — любой период.
def make_report(data, start, end):
    part = data[(data["order_date"] >= start) & (data["order_date"] <= end)]
    return part.groupby("city").agg(orders=("order_id", "count"))

print(make_report(clean, "2026-10-05", "2026-10-11")["orders"].sum())
print(make_report(clean, "2026-10-12", "2026-10-18")["orders"].sum())
817 783

Простыми словами: функция получает данные и даты, а возвращает готовую сводку. Чтобы собрать отчёт за новую неделю, не нужно копировать код — достаточно вызвать функцию с другими датами. Так устроена задача 7.

Автоматизация. Когда отчёт работает в ноутбуке, перенеси его в файл report.py с функцией make_report(start, end) и запускай командой python report.py. В Windows его можно поставить в «Планировщик заданий», чтобы файл собирался сам каждый понедельник.
04 · Ловушки

Четыре ловушки ввода-вывода

1

Excel без with

w = pd.ExcelWriter("r.xlsx") t.to_excel(w) # файл не сохранён, пока не вызван w.close()
with pd.ExcelWriter("r.xlsx") as w: t.to_excel(w, sheet_name="города")

Блок with сам сохраняет и закрывает файл, даже если внутри случилась ошибка.

2

Лишняя колонка индекса

По умолчанию to_excel и to_csv пишут индекс отдельной колонкой. Для таблицы строк добавляй index=False, для сводки по городам индекс как раз нужен.

3

Русский Excel и CSV

Файл из русского Excel часто разделён точкой с запятой и с запятой в дробях: pd.read_csv(f, sep=";", decimal=","). Если видишь одну колонку со всеми данными — проверь sep.

4

Отчёт с датами «вшитыми» в код

Если период записан прямо в коде, через неделю отчёт посчитает старые цифры. Период — это параметры функции: make_report(start, end).

Шпаргалка урока: ввод-вывод

  1. pd.read_csv(f, usecols=[...], parse_dates=["d"]) — нужные колонки и даты
  2. pd.read_csv(f, sep=";", decimal=",", encoding="cp1251") — файл из русского Excel
  3. with pd.ExcelWriter("r.xlsx") as w: t.to_excel(w, sheet_name="лист") — Excel с листами
  4. pd.read_excel("r.xlsx", sheet_name="лист", index_col=0) — прочитать лист
  5. pd.ExcelFile("r.xlsx").sheet_names — список листов
  6. df.to_sql("t", con, index=False); pd.read_sql("SELECT …", con) — SQL через sqlite3
  7. t.to_csv(f, sep=";", decimal=",", encoding="utf-8-sig") — CSV для русского Excel
  8. def make_report(start, end): … — отчёт как функция с параметрами
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Что делает usecols в read_csv?

Ненужные колонки даже не загружаются в память.

2. Зачем писать Excel через with pd.ExcelWriter(...) as w:?

with гарантирует сохранение и закрытие файла.

3. Что вернёт pd.read_sql("SELECT ...", con)?

read_sql выполняет запрос в базе и возвращает результат таблицей pandas.

4. Файл из русского Excel открылся одной колонкой со всеми данными. Что попробовать?

Русский Excel часто разделяет колонки точкой с запятой.

5. Как сделать отчёт, который на следующей неделе посчитает новые цифры?

Период — параметр функции: make_report(start, end).
