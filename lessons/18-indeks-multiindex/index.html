Индекс и MultiIndex: подписи строк в несколько этажей

У каждой таблицы pandas есть подписи строк — индекс. Пока мы почти не обращали на него внимания, но после groupby по двум колонкам или pivot_table pandas сам строит индекс в несколько этажей. Сегодня учимся управлять индексом: ставить и убирать его, доставать строки по подписям, дополнять пропущенные даты и работать с MultiIndex.

02 · Теория

Индекс — подписи строк

Простыми словами

Представь журнал в школе. Слева — фамилии учеников, справа — оценки. Фамилии не оценки, это подписи строк: по ним ищут нужную строку. В pandas такие подписи называются индексом.

  • Когда ты читаешь CSV, индекс — просто номера 0, 1, 2… Он есть всегда, даже если ты его не видишь.
  • После groupby("store") индексом становятся названия магазинов: по ним удобно искать — by_store.loc["Chilonzor"].
  • set_index("колонка") делает колонку подписями строк, reset_index() — возвращает подписи обратно в обычную колонку.
  • При сложении и делении двух таблиц pandas сопоставляет строки по подписям, а не по порядку (это ты уже видел в уроке 9).

Простыми словами: каждая строка — день × магазин × категория. Индекс здесь — номера 0, 1, 2…: они ничего не значат, просто порядковые.

Простыми словами: .loc["Chilonzor"] — «дай строку с подписью Chilonzor». Не нужно помнить, на каком она месте: ищем по имени, как фамилию в журнале.

Простыми словами: reset_index() нужен, когда результат группировки надо сохранить в файл, соединить через merge или отсортировать по магазину как по колонке. set_index — обратное действие.

4. sort_index — сортировка по подписям.

Простыми словами: sort_values сортирует по значениям (выручке), sort_index — по подписям (названиям). По убыванию алфавита первым идёт Yunusobod.

Пропущенные подписи: reindex

Если магазин был закрыт, в выгрузке за эти дни просто нет строк. Среднее «за день» тогда посчитается только по рабочим дням, а на графике дни ремонта исчезнут. reindex(список) выстраивает строки строго по готовому списку подписей: чего не было — появится с NaN, а fill_value=0 поставит ноль.

  1. kogonвыручка магазина Kogon по дням: дней с данными 85 из 92
  2. pd.date_range(...)полный календарь: каждый день без пропусков
  3. kogon.reindex(дни, fill_value=0)дни ремонта стали нулями — их 7 в августе
5. reindex: найти дни, которых нет в данных.
kogon = df[df["store"] == "Kogon"].groupby("date")["revenue"].sum()
aug = pd.date_range("2026-08-01", "2026-08-31")
full = kogon.reindex(aug, fill_value=0)
print(len(kogon.loc["2026-08"]), "дней в данных за август,", len(full), "дней в календаре")
full[full == 0].index.strftime("%d.%m").tolist()
24 дней в данных за август, 31 дней в календаре ['10.08', '11.08', '12.08', '13.08', '14.08', '15.08', '16.08']

Простыми словами: pd.date_range(start, end) делает список всех дней подряд. После reindex у каждого дня августа есть строка, а дни ремонта видны как нули.

03 · Теория

MultiIndex — подписи в несколько этажей

Простыми словами

Адрес на конверте: страна → город → улица. Это подпись в несколько этажей. Когда ты группируешь по двум колонкам, pandas подписывает строки так же: регион → магазин. Это и есть MultiIndex.

  • Этажи называются уровнями (level). У groupby(["region", "store"]) уровень 0 — region, уровень 1 — store.
  • .loc["Бухара"] — все строки верхнего уровня «Бухара». .loc[("Бухара", "Ark")] — одна строка по полному адресу.
  • xs("Электроника", level="category") — «срез» по нижнему уровню: все строки, где категория — Электроника.
  • groupby(level="region").sum() — итог по верхнему уровню без повторной группировки исходных данных.
6. MultiIndex после группировки по двум колонкам.
rs = (df.groupby(["region", "store"])["revenue"].sum() / 1e6).round(1)
print(rs.index.names)
rs
['region', 'store'] region store Бухара Ark 1540.2 Gijduvon 875.0 Kogon 998.1 Самарканд Registon 2381.8 Siyob 1772.7 Ташкент Chilonzor 3320.1 Sergeli 2209.5 Yunusobod 2892.8 Фергана Markaz 1879.8 Quvasoy 1235.9 Name: revenue, dtype: float64

Простыми словами: слева два этажа подписей. Pandas не повторяет название региона в каждой строке — так таблицу легче читать.

7. .loc по верхнему уровню и по полному адресу.
print(rs.loc["Бухара"])
print()
rs.loc[("Ташкент", "Chilonzor")]
store Ark 1540.2 Gijduvon 875.0 Kogon 998.1 Name: revenue, dtype: float64 3320.1

Простыми словами: rs.loc["Бухара"] вернул все магазины Бухары, а верхний этаж пропал — он одинаковый. Полный адрес пишут кортежем в круглых скобках.

8. xs — срез по нижнему уровню. Выручка электроники в каждом регионе.
rc = df.groupby(["region", "category"])["revenue"].sum()
(rc.xs("Электроника", level="category") / 1e6).round(1)
region Бухара 385.0 Самарканд 731.8 Ташкент 2055.3 Фергана 473.7 Name: revenue, dtype: float64

Простыми словами: через .loc нижний уровень так просто не достать, а xs (cross-section, «поперечный срез») берёт нужное значение на любом этаже.

9. Итог по уровню и доля внутри группы.
region_total = rc.groupby(level="region").sum()
share = rc / region_total * 100
share.round(1).head(5)
region category Бухара Бытовая химия 14.1 Детские товары 19.2 Напитки 11.2 Продукты 44.1 Электроника 11.3 Name: revenue, dtype: float64

Простыми словами: rc / region_total — деление «по подписям»: у rc два этажа, у region_total один, и pandas сам подставит итог региона в каждую его строку. Получилась доля категории внутри своего региона.

Многоэтажные названия колонок

Если в agg передать словарь «колонка → список функций», то этажи появятся уже у названий колонок: сверху units и revenue, снизу sum, mean, max. Такую таблицу неудобно сохранять и по ней трудно обращаться к колонкам, поэтому этажи «сплющивают» в одну строку: units_sum, revenue_max.

10. Сплющить MultiIndex у колонок.
t = df.groupby("region").agg({"units": ["sum", "mean"], "revenue": ["sum", "max"]})
print(t.columns.tolist())
t.columns = ["_".join(c) for c in t.columns]
t.round(1)
[('units', 'sum'), ('units', 'mean'), ('revenue', 'sum'), ('revenue', 'max')] units_sum units_mean revenue_sum revenue_max region Бухара 104384 77.6 3413311100 9821900 Самарканд 113959 123.9 4154448300 12113000 Ташкент 220492 159.8 8422448300 16045700 Фергана 93598 101.7 3115657600 10469300

Простыми словами: t.columns — список пар («units», «sum»). "_".join(пара) склеивает пару через подчёркивание. Именованная агрегация из урока 8 (agg(units_sum=("units", "sum"))) даёт плоские названия сразу — поэтому её и советуют.

04 · Ловушки

Пять ловушек индекса

1

Потерянная колонка после set_index

t = df.set_index("store") t["store"] # KeyError: store теперь не колонка
t.index # подписи строк t.reset_index() # store снова колонка

После set_index колонка уходит в подписи строк. Обращаться к ней как к колонке нельзя, пока не сделаешь reset_index.

2

Дни, которых нет

Если в какие-то дни продаж не было, строк за них нет совсем. Среднее «за день» окажется завышенным, а пропуски не будут видны. Дополняй календарь через reindex(pd.date_range(...), fill_value=0).

3

Полный адрес без кортежа

rs.loc["Ташкент", "Chilonzor"] # у DataFrame это читается как «строка, колонка»
rs.loc[("Ташкент", "Chilonzor")]

У Series запись через запятую сработает, а у DataFrame вторая часть будет считаться колонкой. Полный адрес в MultiIndex надёжнее писать кортежем в круглых скобках.

4

reset_index в цепочке забыли

merge и to_csv работают с колонками. Если таблица после группировки уходит дальше в merge или в файл, сделай .reset_index() — иначе ключи останутся в индексе.

5

Многоэтажные колонки в файле

Таблица с MultiIndex в колонках сохраняется в CSV двумя строками заголовков, и Excel покажет её неудобно. Перед сохранением сплющи названия: t.columns = ["_".join(c) for c in t.columns].

Шпаргалка урока: индекс и MultiIndex

  1. df.set_index("store") / t.reset_index() — колонка ↔ подписи строк
  2. s.loc["Chilonzor"] — строка по подписи
  3. s.sort_index() — сортировка по подписям
  4. s.reindex(pd.date_range(a, b), fill_value=0) — дополнить пропущенные дни
  5. rs.loc["Бухара"] / rs.loc[("Бухара", "Ark")] — MultiIndex: уровень / полный адрес
  6. rc.xs("Электроника", level="category") — срез по нижнему уровню
  7. rc.groupby(level="region").sum() — итог по уровню
  8. t.columns = ["_".join(c) for c in t.columns] — сплющить названия колонок
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Что делает reset_index()?

Подписи (например, названия магазинов) становятся колонкой, а индексом снова становятся номера 0, 1, 2…

2. Какой индекс будет у результата df.groupby(["region", "store"])["revenue"].sum()?

Группировка по двум колонкам даёт подписи в два этажа.

3. Как взять все категории региона «Бухара» из Series с MultiIndex region → category?

.loc по значению верхнего уровня возвращает все его строки.

4. Магазин не работал 7 дней, и в выгрузке за эти дни нет строк. Что сделать перед подсчётом выручки по дням?

reindex добавит недостающие дни, и они станут видны как нули.

5. Чем sort_index отличается от sort_values?

Одна сортирует по названиям (индексу), другая — по содержимому.

Частая ошибка. Если сначала сделать reset_index без name, колонка значений будет называться revenue — тогда переименуй её или сразу передай name="revenue_mln".
