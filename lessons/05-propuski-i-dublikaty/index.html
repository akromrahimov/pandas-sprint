02 · Теория

Пустая клетка и двойная строка

Простыми словами

Представь классный журнал. Иногда учитель не поставил оценку — клетка пустая. Иногда завуч переписал ученика в журнал два раза — он записан дважды. Если не заметить ни то, ни другое, средняя оценка класса получится неправильной.

  • Пропуск — пустая клетка. В pandas она выглядит как NaN (Not a Number, «не число») или <NA>.
  • isna() — «здесь пусто?». На каждую клетку отвечает True (пусто) или False (есть значение). notna() — наоборот.
  • fillna(значение) — «заполни пустые клетки вот этим».
  • dropna() — «выкинь строки, где есть пустая клетка». Опасно: выкидывает строку, даже если пусто только в одной неважной колонке.
  • Дубликат — строка, которая повторяет другую. duplicated() отвечает «эта строка уже встречалась выше?» (True/False). drop_duplicates() удаляет повторы.

Главная мысль дня: пропуск — это тоже информация. Пустой промокод значит «пришёл без промокода» — заполняем словом "none". Пустая цена — потеряли, но знаем тариф — восстанавливаем по тарифу. Пустой возраст — не знаем, и 0 туда ставить нельзя: человеку не 0 лет.

03 · Теория

Семь приёмов: найти пустое, заполнить по смыслу, убрать дубли

Как читать код
  • df.isna() — таблица того же размера, но вместо значений True/False. .sum() после неё считает True в каждой колонке (True = 1, False = 0).
  • .isna().mean() * 100 — среднее из True/False — это доля True. Умножили на 100 — получили процент. Этим же приёмом считается любая доля: (df["city"] == "Ташкент").mean() * 100.
  • .fillna("none") — в скобках то, чем заполнить. Можно число, слово или целую Series: тогда каждая пустая клетка берёт значение из той же строки этой Series.
  • df["plan"].map(prices) — map («сопоставить»): берёт каждое значение plan и ищет его в словаре prices. "basic" → 39000. Получается Series с ценой по тарифу.
  • drop_duplicates(subset="user_id", keep="last") — subset: сравнивать строки только по user_id. keep="last": из одинаковых оставить последнюю сверху вниз.
  • ( df.drop_duplicates() .sort_values(...) .drop_duplicates(...) ) — цепочка: каждая точка берёт результат предыдущего шага. Круглые скобки вокруг позволяют переносить строки.
  • dropna(subset=["age"]) — выкинуть строки, где пусто именно в age. Без subset выкинет строку, где пусто хоть где-то.

Каждый вывод ниже получен реальным запуском pandas 3.0 на файле TezKino. Твои цифры должны совпасть.

1. isna().sum() — сколько пустых.
import pandas as pd

df = pd.read_csv("tezkino_users.csv")
df.isna().sum()

Простыми словами: в 4 колонках есть пустые клетки. Больше всего в promo_code — 755. Это не «сломанные данные»: человек просто пришёл без промокода. А price 18 — это настоящая потеря, цена должна быть у всех.

2. isna().mean() * 100 — доля пустых.
(df.isna().mean() * 100).round(1)
user_id 0.0 signup_date 0.0 city 0.0 plan 0.0 price 1.5 promo_code 61.9 source 0.0 age 6.5 last_login 9.6 churned 0.0 updated_at 0.0 dtype: float64

Простыми словами: mean() от True/False — это доля True. 755 пустых из 1 220 = 61.9%. Не нужно делить shape[0] на shape[0] — .mean() делает это сам. Это ровно тот приём, который ты пропускал 3 раза.

3. fillna — COALESCE.
promo = df["promo_code"].fillna("none")
promo.value_counts()
promo_code none 755 FREEWEEK 156 START50 156 KINO30 153 Name: count, dtype: int64

Простыми словами: пустые клетки получили слово "none". Теперь «без промокода» — нормальная группа, и value_counts() её видит. Без fillna value_counts пустые просто пропускает.

4. fillna из другой колонки через map.
prices = {"basic": 39000, "standard": 69000, "premium": 119000}
price_full = df["price"].fillna(df["plan"].map(prices))
print(df["price"].isna().sum(), price_full.isna().sum())
18 0

Простыми словами: мы знаем тариф клиента, а у каждого тарифа своя цена. map(prices) делает колонку «цена по тарифу», а fillna берёт из неё значение только там, где цена пустая. Было 18 пустых — стало 0.

5. duplicated — полные дубли.
print(df.duplicated().sum())
print(df.drop_duplicates().shape)
40 (1180, 11)

Простыми словами: 40 строк — точные копии строк выше (все 11 колонок совпадают). CRM выгрузила их дважды. После удаления — 1 180 строк. Но это ещё не число клиентов.

6. Один клиент — две версии.
df1 = df.drop_duplicates()

7. Последняя версия — ROW_NUMBER.
users = (df.drop_duplicates()
           .sort_values("updated_at")
           .drop_duplicates(subset="user_id", keep="last"))
print(len(users), users["user_id"].is_unique)
1150 True

Простыми словами: сначала сортируем от старых к новым, потом для каждого user_id оставляем последнюю (самую новую) строку. Получилось 1 150 клиентов, и is_unique (все ли значения разные) = True. Значит, у Нигоры не 1 220 подписчиков, а 1 150.

История про конфеты: пустой не значит ноль

Пять друзей пишут, сколько им лет: 10, 10, 10, 10 и один забыл написать. Средний возраст — 10: считаем только тех, кто написал (40 / 4). Если вместо пустого поставить 0, выйдет (10+10+10+10+0) / 5 = 8. Стали ли друзья младше? Нет. Мы просто сами придумали малыша нулевого возраста.

4 друга × 10 летрозовый — пусто, а не 0

Так и у Нигоры: 79 человек без возраста. С fillna(0) средний возраст падает с 37.9 до 35.5. Правило: заполняй пропуск, только если знаешь, что там должно быть (промокода нет → "none", цена → по тарифу). Если не знаешь — оставь пустым, mean() его сам пропустит.

Бонус. dropna без subset — выкидывает почти всё.
print(len(df.dropna()), len(df.dropna(subset=["age"])))
387 1141

Простыми словами: dropna() без настроек выкинул строки, где пусто хоть где-то. А пусто в promo_code у 62% людей. Осталось 387 из 1 220 — ты потерял 68% клиентов. С subset=["age"] ушли только 79 строк без возраста.

Правило аналитика. Перед любым подсчётом «сколько клиентов» спроси: одна строка = один клиент? Проверь df["user_id"].is_unique. Если False — сначала дубли, потом метрики.

Шпаргалка урока: 8 строк, которые надо помнить

  1. df.isna().sum() — сколько пустых в каждой колонке
  2. df.isna().mean() * 100 — доля пустых, % (и любая доля: (mask).mean() * 100)

05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. В колонке 1 220 строк, isna().sum() = 755. Как получить долю пропусков в %?

mean() от True/False — это доля True. 755 / 1220 = 0.619 → 61.9%.

2. Что вернёт df["age"].fillna(0).mean(), если у 79 человек нет возраста?

79 нулей попали в среднее: 37.9 → 35.5. Пустое лучше оставить пустым — mean() пропускает NaN сам.

3. Чем df.dropna() опасен на этом файле?

Пусто в promo_code у 62% — и они все вылетают. Пиши dropna(subset=["age"]).

4. df.duplicated().sum() = 40, а df["user_id"].nunique() = 1150 при 1 220 строках. Почему 1 220 − 40 ≠ 1 150?

40 — точные копии. Ещё 30 клиентов записаны дважды с разными данными (сменили тариф). 1220 − 40 − 30 = 1150.

5. Как оставить для каждого user_id самую новую запись?

keep="last" — последняя в таблице. Самой новой она станет только после сортировки по дате.
