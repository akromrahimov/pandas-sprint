02 · Теория

Из дней — в недели и месяцы

Простыми словами

Представь дневник, где каждый день записано, сколько бутылок молока продано. Чтобы понять, растёт ли лавка, ты не читаешь все 270 дней по очереди — ты складываешь их по неделям или месяцам.

  • Временной ряд — таблица, где каждая строка — момент времени (день), а дата стоит слева в индексе.
  • set_index("date") — сделать колонку с датой индексом. Сначала её нужно превратить в дату (урок 15).
  • resample("W") — «разложи дни по неделям», "MS" — по месяцам (метка — первое число месяца). После resample пишут, что сделать с днями внутри: .sum(), .mean().
  • asfreq("D") — «покажи каждый день по порядку». Дни, которых нет в файле, станут пустыми строками — так находят пропуски.

resample — это groupby по календарю. В уроке 8 ты делил заказы на кучки по городу. Здесь делишь дни на кучки по месяцу: все дни января в одну кучку, февраля — в другую. Потом в каждой кучке что-то считаешь: сумму, среднее.

03 · Теория

Убрать шум и сравнить с прошлым

Как читать код
  • rolling(7).mean() — «для каждого дня посчитай среднее за 7 последних дней». Скачки выходных сглаживаются, остаётся тренд.
  • shift(1) — «сдвинь на одну строку вниз»: в строке текущего месяца окажется значение прошлого.
  • diff() — разница с прошлой строкой, pct_change() — изменение в долях: 0.12 значит +12%.

Скользящее окно — как рамка шириной 3 дня, которую двигают по календарю на один день. Для каждого положения рамки считают среднее того, что в неё попало. Ниже это видно на маленьком примере из 7 дней.

4. Как «ползёт» окно — на игрушечном примере. 7 дней продаж и среднее за 3 дня.
toy = pd.Series([10, 12, 30, 11, 13, 12, 14],
                index=pd.date_range("2026-06-01", periods=7), name="заказы")
pd.DataFrame({
    "заказы": toy,
    "среднее_3_дня": toy.rolling(3).mean().round(1),
    "вчера": toy.shift(1),
    "разница_с_вчера": toy.diff(),
    "рост_%": (toy.pct_change() * 100).round(1),
})
заказы среднее_3_дня вчера разница_с_вчера рост_% 2026-06-01 10 NaN NaN NaN NaN 2026-06-02 12 NaN 10.0 2.0 20.0 2026-06-03 30 17.3 12.0 18.0 150.0 2026-06-04 11 17.7 30.0 -19.0 -63.3 2026-06-05 13 18.0 11.0 2.0 18.2 2026-06-06 12 12.0 13.0 -1.0 -7.7 2026-06-07 14 13.0 12.0 2.0 16.7

Простыми словами: 3 июня: среднее (10 + 12 + 30) / 3 = 17,3. 4 июня окно сдвинулось: (12 + 30 + 11) / 3 = 17,7. Скачок 30 «размазался» по трём дням — это и есть сглаживание. В первые два дня среднего нет: в рамке ещё меньше 3 дней. shift(1) просто кладёт рядом вчерашнее число, diff — разницу с ним, pct_change — эту разницу в процентах.

5. Окно с пропусками: min_periods. Если в рамке есть пустой день.
gap = pd.Series([10, 12, None, 11, 13], index=pd.date_range("2026-06-01", periods=5))
pd.DataFrame({
    "заказы": gap,
    "rolling(3)": gap.rolling(3).mean().round(1),
    "rolling(3, min_periods=2)": gap.rolling(3, min_periods=2).mean().round(1),
})
заказы rolling(3) rolling(3, min_periods=2) 2026-06-01 10.0 NaN NaN 2026-06-02 12.0 NaN 11.0 2026-06-03 NaN NaN 11.0 2026-06-04 11.0 NaN 11.5 2026-06-05 13.0 NaN 12.0

Простыми словами: обычное окно не считает среднее, пока в нём есть пустой день: одна дыра «гасит» три строки. min_periods=2 говорит: «считай, если в рамке есть хотя бы 2 настоящих числа». Это понадобится в задаче 5.

Простыми словами: shift(1) поставил рядом прошлый месяц, pct_change посчитал рост в процентах. У января роста нет (NaN): сравнивать не с чем.

8. Срез по датам. Взять неделю по календарю — приём для задачи 6.
week = s.loc["2026-06-10":"2026-06-16"]
print(len(week), "дней")

Простыми словами: когда дата в индексе, строки можно брать срезом «с какого по какое число». В отличие от обычных срезов Python, обе даты включены: здесь ровно 7 дней.

Правило аналитика. Сравнивай равные периоды. Февраль короче марта, а в месяце с пропущенными днями сумма меньше. Если дней разное число, сравнивай среднее за день, а не сумму.
04 · Ловушки

Пять ловушек временных рядов

1

resample без индекса-даты

df.resample("MS").sum() # TypeError: нужен DatetimeIndex
df.assign(date=pd.to_datetime(df["date"])).set_index("date").resample("MS").sum()

resample работает только когда дата — индекс и это настоящая дата, а не текст.

2

Старое обозначение месяца

s.resample("M").sum() # в pandas 3.0 — ошибка
s.resample("MS").sum() # или "ME" — метка в конце месяца

В pandas 3.0 убрали короткое "M". Пиши "MS" (начало месяца) или "ME" (конец месяца).

3

Пропущенные дни

4 дня в файле отсутствуют. В rolling(7) окно из 7 строк тогда захватит 8–9 календарных дней. Для точности сначала asfreq("D"), чтобы пропуски стали видны.

4

pct_change в процентах

pct_change() возвращает доли: 0.12 — это 12%. Не забудь умножить на 100, прежде чем писать «рост 0.12%».

5

Сравнение акции с «любой» неделей

Эффект акции сравнивают с похожим периодом прямо перед ней, а не со средним за год: продажи всё время растут, и год даст завышенный эффект.

Шпаргалка урока: 8 строк про временные ряды

  1. s = df.assign(date=pd.to_datetime(df["date"])).set_index("date") — дата в индекс
  2. s.asfreq("D") — каждый день по порядку, пропуски видны
  3. s.resample("W").sum() — по неделям
  4. s.resample("MS").sum() — по месяцам
  5. s["x"].rolling(7).mean() — скользящее среднее за 7 дней
  6. s["x"].shift(1) — прошлое значение
  7. s["x"].pct_change() * 100 — рост в %
  8. s.loc["2026-06-10":"2026-06-16"] — срез по датам
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Что нужно, чтобы работал resample?

resample раскладывает строки по периодам индекса, поэтому индекс должен быть datetime.

2. Что делает rolling(7).mean()?

Окно из 7 строк сдвигается по ряду, для каждой строки считается среднее внутри окна.

3. pct_change() вернул 0.25. Что это значит?

pct_change даёт долю: 0.25 × 100 = 25%.

4. Как найти дни, которых нет в файле?

asfreq("D") вставляет строку на каждый календарный день, отсутствующие дни становятся NaN.

5. С чем честно сравнить неделю акции?

Похожий соседний период убирает влияние тренда и сезона.
