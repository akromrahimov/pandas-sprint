02 · Теория

Сначала вопрос, потом график

Простыми словами

График — это ответ на один вопрос. Если не знаешь вопроса, получится красивая, но бесполезная картинка.

  • Как менялось во времени? → линия (line). Время всегда слева направо.
  • Кто больше, кто меньше? → столбцы (bar), отсортированные. Длинные подписи — горизонтальные столбцы (barh).
  • Какие значения встречаются чаще? → гистограмма (hist): столбики «сколько чеков попало в каждый интервал».
  • Круговые диаграммы почти всегда хуже столбцов: глаз плохо сравнивает углы.

Как читать код: series.plot(kind="bar") — «нарисуй эту колонку столбиками». ax — сама картинка-график, через неё добавляют подписи: ax.set_title(…), ax.set_ylabel(…).

Из чего состоит график
  • fig (figure) — весь лист бумаги. На нём может быть один график или несколько.
  • ax (axes) — один график на листе: оси, линии, столбики. .plot() возвращает именно его, поэтому пишут ax = series.plot(...).
  • title — заголовок над графиком, xlabel / ylabel — подписи осей снизу и слева.
  • Откуда pandas берёт оси? По горизонтали — подписи строк (index): месяцы, дни, категории. По вертикали — сами значения. Поэтому перед графиком данные сначала группируют и сортируют, а рисуют уже готовую Series.

pandas рисует графики с помощью библиотеки matplotlib: ты пишешь .plot() у pandas, а картинку собирает matplotlib. Отдельно matplotlib (plt) нужен только для сложных случаев — например, нескольких графиков на одном листе.

1. Линия: выручка по месяцам.
monthly = sales.set_index("date").resample("MS")["revenue"].sum() / 1e6
ax = monthly.plot(marker="o", figsize=(7, 3.5))
ax.set_title("Выручка Sutli выросла на ⟦fmt(growth)⟧% с января по сентябрь")
ax.set_ylabel("млн сум")
ax.set_xlabel("")

Простыми словами: заголовок — это сразу вывод, а не «График выручки». Подпись оси говорит, в чём измеряем.

2. Горизонтальные столбцы: категории книг.
cat = orders.groupby("category")["amount"].sum().sort_values() / 1e6
ax = cat.plot(kind="barh", figsize=(7, 3), color="#6C5CE7")
ax.set_title("Больше всего денег приносят художественные книги")
ax.set_xlabel("выручка, млн сум")
ax.set_ylabel("")

Простыми словами: сортировка делает вывод очевидным: самый длинный столбец сверху. Горизонтальные столбцы удобны, когда подписи длинные.

3. Гистограмма: какие чеки обычные.
ax = orders["amount"].plot(kind="hist", bins=30, figsize=(7, 3), color="#E70488")
ax.axvline(orders["amount"].median(), color="black", linestyle="--")
ax.set_title("Типичный чек — около ⟦fmt(med)⟧ сум (пунктир — медиана)")
ax.set_xlabel("сумма заказа, сум")

Простыми словами: видно, что большинство чеков небольшие, а дорогие встречаются редко: хвост справа. Пунктирная линия показывает медиану. bins=30 — на сколько «корзинок» по сумме разложить заказы: мало корзинок — грубо, слишком много — шумно.

4. Плохой и хороший график из одних и тех же данных.
fig, axes = plt.subplots(1, 2, figsize=(10, 3))
raw = orders.groupby("category")["amount"].sum()
raw.plot(kind="bar", ax=axes[0])
(raw.sort_values() / 1e6).plot(kind="barh", ax=axes[1], color="#6C5CE7")
axes[1].set_title("Художественные книги приносят больше всего денег")
axes[1].set_xlabel("млн сум")
axes[1].set_ylabel("")
fig.tight_layout()

Простыми словами: слева — как получается «по умолчанию»: категории по алфавиту, подписи наклонены, длинные числа на оси, нет заголовка. Справа те же данные: отсортированы, переведены в миллионы, есть заголовок-вывод и подпись оси. Вывод виден за секунду.

03 · Теория

Несколько графиков и подписи

Как сделать график понятным
  • Заголовок-вывод: «Выходные дают на 30% больше заказов», а не «Заказы по дням».
  • Подписи осей с единицами: «млн сум», «заказов в день».
  • Без лишнего: одна-две краски, без 3D и теней.
  • fig, axes = plt.subplots(1, 2) — «сделай полотно с двумя графиками рядом». В каждый рисуют через ax=axes[0].
5. Две линии на одном графике. Приём для задачи 5: второй ряд рисуют на тот же ax.
daily = sales.set_index("date")["orders"]
ax = daily.plot(color="lightgray", linewidth=1, figsize=(8, 3), label="по дням")
daily.rolling(7).mean().plot(ax=ax, color="#E70488", linewidth=2.5, label="среднее за 7 дней")
ax.legend()
ax.set_xlabel("")

Простыми словами: первый .plot() создаёт график и возвращает ax. Второй получает ax=ax — «рисуй туда же». Шумный дневной ряд светло-серый и тонкий, тренд — яркий и толстый: глаз сразу видит главное. label и ax.legend() добавляют подписи линий.

6. Заголовок из данных. Цифра в заголовке считается кодом, а не пишется руками.
weekend = sales["date"].dt.dayofweek >= 5
avg = sales.groupby(weekend)["orders"].mean()
diff = round((avg[True] / avg[False] - 1) * 100)
print(avg.round(1))
f"В выходные заказов на {diff}% больше, чем в будни"
date False 143.8 True 187.3 Name: orders, dtype: float64 'В выходные заказов на 30% больше, чем в будни'

Простыми словами: группировка по маске даёт две строки: False — будни, True — выходные. Сравниваем их и вставляем результат в f-строку. Если данные обновятся, заголовок пересчитается сам и не соврёт.

7. Два графика рядом.
fig, axes = plt.subplots(1, 2, figsize=(10, 3.2))
wd = sales.groupby(sales["date"].dt.dayofweek)["orders"].mean()
wd.index = ["Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс"]
wd.plot(kind="bar", ax=axes[0], color="#6C5CE7", title="Заказов в день по дням недели")
sales.set_index("date")["orders"].rolling(7).mean().plot(ax=axes[1], color="#E70488",
                                                          title="Заказы: среднее за 7 дней")
axes[0].tick_params(axis="x", rotation=0)
axes[1].set_xlabel("")
fig.tight_layout()

Простыми словами: слева — суббота и воскресенье заметно выше будней. Справа — сглаженный тренд: рост и всплеск июньской акции.

Правило аналитика. Перед тем как отправить график, закрой текст и спроси себя: «Что человек поймёт за 5 секунд?». Если ответ не совпадает с заголовком — переделай.
04 · Ловушки

Пять ошибок в графиках

1

Несортированные столбцы

Столбцы в алфавитном порядке заставляют глазами искать максимум. Сортируй: .sort_values() перед .plot(kind="barh").

2

Линия для категорий

Линия соединяет точки и намекает на «движение» между ними. Для городов или категорий нужна не линия, а столбцы.

3

Ось не с нуля у столбцов

Если ось столбцов начинается не с нуля, разница 5% выглядит как разница в два раза. Для столбцов ось всегда с нуля (pandas так и делает по умолчанию).

4

Нет единиц измерения

«245» — это заказы, тысячи сум или миллионы? Подпиши ось: ax.set_ylabel("млн сум").

5

Заголовок-описание вместо вывода

ax.set_title("Выручка по месяцам")
ax.set_title("Выручка выросла на 25% за 9 месяцев")

Заголовок-вывод экономит время читателя и показывает, что аналитик понял данные.

Шпаргалка урока: графики

  1. s.plot() — линия (по умолчанию)
  2. s.plot(kind="bar") / kind="barh" — столбцы
  3. s.plot(kind="hist", bins=30) — гистограмма
  4. ax = s.plot(...); ax.set_title("вывод") — заголовок
  5. ax.set_xlabel(...) / ax.set_ylabel(...) — подписи осей
  6. fig, axes = plt.subplots(1, 2, figsize=(10, 3)) — два графика рядом
  7. s.plot(ax=axes[0]) — нарисовать в нужное место
  8. ax.axvline(x, linestyle="--") — линия-отметка, например медиана
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Какой график для вопроса «как менялась выручка по месяцам»?

Изменение во времени — линия, время слева направо.

2. Какой график покажет, какие суммы чеков встречаются чаще?

Гистограмма раскладывает значения по интервалам и показывает, сколько попало в каждый.

3. Какой заголовок лучше?

Заголовок-вывод сразу говорит, что увидеть на графике.

4. Что делает plt.subplots(1, 2)?

1 строка, 2 столбца — два графика рядом, обращаться к ним через axes[0] и axes[1].

5. Почему столбцы сортируют перед графиком?

Отсортированные столбцы читаются мгновенно, глазу не нужно искать максимум.
