OVER (PARTITION BY), HAVING, ROW_NUMBER

Оконные функции ты пишешь в SQL каждый день. В pandas у каждой есть короткая пара.

SQLpandasЧто получится

COUNT(*) OVER (PARTITION BY merchant)df.groupby("merchant")["tx_id"].transform("size")размер группы

ROW_NUMBER() OVER (PARTITION BY category ORDER BY cashback DESC) <= 2df.sort_values("cashback", ascending=False).groupby("category").head(2)топ-2 в каждой группе

Отличие от SQL. В SQL HAVING возвращает одну строку на группу. В pandas filter возвращает все исходные строки групп, которые прошли проверку: 1 653 операции у 14 партнёров, а не 14 строк. Если нужна одна строка на партнёра — сначала size(), потом обычная маска.

Не знаешь SQL — просто пропусти: для курса он не нужен.

groupby продвинутый: доля внутри группы, transform и filter

В уроке 8 groupby сжимал таблицу: одна строка на город. Сегодня два новых умения. transform — посчитать итог группы и приклеить его к каждой строке, чтобы сравнить строку с её группой. filter — оставить только те группы, которые прошли условие, например «партнёры, у которых хотя бы 40 операций».

02 · Теория

transform = посчитать по коробке и вернуть ответ каждому

Простыми словами

Вчера мы раскладывали конфеты по коробкам и писали один листочек: «в красной коробке 5». Таблица сжималась: было 1 800 строк — стало 6. Но иногда нужно другое: чтобы каждая конфета знала, сколько всего конфет в её коробке. Тогда можно сказать: «я — одна из 5 красных, то есть 20% красной коробки».

  • agg / sum() после groupby — сжимает: одна строка на группу. Как в уроке 8.
  • transform("sum") — считает то же самое, но раздаёт ответ обратно каждой строке. Длина не меняется: было 1 800 строк — осталось 1 800.
  • Доля внутри группы = значение строки / итог её группы. «Сколько процентов кэшбэка кафе забирает Coffee Lab».
  • Доля от общего итога = итог группы / итог всей таблицы: s / s.sum(). «Сколько процентов всего кэшбэка забирает Электроника».
  • filter(...) — выбрасывает целые коробки, которые не прошли проверку, а строки из хороших коробок оставляет как есть.
  • lambda g: len(g) >= 40 — маленькая функция-проверка: «дай мне коробку g, я скажу да или нет». lambda — функция без имени, записанная в одну строку.

Главная мысль дня: доля по числу операций и доля по деньгам — разные вещи. Мадина посчитала операции. Бюджет кэшбэка — это деньги.

Пять настоящих строк файла. Справа — колонка, которую сегодня добавит transform: итог кэшбэка категории, приклеенный к каждой строке.

03 · Теория

Восемь приёмов: доли, окна и фильтр групп

Как читать код
  • cb / cb.sum() — cb это Series «категория → кэшбэк». cb.sum() — одно число (весь кэшбэк). Деление Series на число делит каждое значение на это число.
  • .transform("sum") — в кавычках имя функции, как в agg. Результат — Series той же длины и с теми же бирками строк, что df. Поэтому её можно сразу положить в новую колонку: df["cat_cb"] = ….
  • a / b двух Series — pandas делит строку на строку по биркам (Index), не по месту. Бирки у df и transform совпадают — всё делится правильно.
  • .filter(lambda g: len(g) >= 40) — lambda g: «возьми коробку и назови её g». len(g) — сколько строк в коробке. >= 40 — ответ True/False. True — коробку оставить.
  • .groupby("category").head(2) — «из каждой коробки возьми первые 2 строки». Поэтому сначала sort_values: первые = самые большие.
  • sort_values(["category", "cashback"], ascending=[True, False]) — сортировка по двум колонкам: категория по алфавиту, внутри неё кэшбэк от большего (урок 3).

04 · Ловушки

Пять ошибок, на которых спотыкается большинство

1

Положить результат sum() в колонку

df["x"] = df.groupby("category")["cashback"].sum() # 1 800 NaN
df["x"] = df.groupby("category")["cashback"].transform("sum")

sum() вернул 6 строк с бирками «Кафе», «Такси»… А у df бирки 0…1799. Совпадений нет — pandas молча пишет NaN во все 1 800 строк. Для колонки — только transform.

2

Доля операций вместо доли денег

x = df.groupby("category").size(); x / x.sum() # Продукты 29.2%
cb = df.groupby("category")["cashback"].sum(); cb / cb.sum() # Продукты 4.4%

Вопрос про бюджет — считай деньги. 526 операций по 1% кэшбэка дешевле 81 покупки электроники.

3

filter без lambda

df.groupby("merchant").filter(len(df) >= 40) # TypeError: 'bool' object is not callable
df.groupby("merchant").filter(lambda g: len(g) >= 40)

filter ждёт функцию, которую он сам вызовет для каждой коробки. len(df) посчитался один раз для всей таблицы — получилось просто True.

4

head(2) без сортировки

df.groupby("category").head(2) # первые 2 по порядку в файле
df.sort_values("cashback", ascending=False).groupby("category").head(2)

head берёт первые строки так, как они лежат. «Топ» появляется только после sort_values — как ORDER BY внутри OVER.

5

Доля внутри группы, делённая на общий итог

m["cashback"] / m["cashback"].sum() # Choyxona Plus 7.9% — от всего банка
m["cashback"] / m.groupby("category")["cashback"].transform("sum") # 42.4% кафе

Оба числа правильные, но отвечают на разные вопросы. Перед делением скажи вслух: «доля от чего?».

Шпаргалка урока: 8 строк, которые надо помнить

  1. df["segment"] = df["segment"].str.strip().str.lower() — сначала чистый ключ
  2. cb = df.groupby("category")["cashback"].sum(); cb / cb.sum() * 100 — доля от общего итога
  3. df.groupby("category")["cashback"].transform("sum") — SUM() OVER (PARTITION BY)
  4. df["cashback"] / df.groupby("category")["cashback"].transform("sum") — доля внутри группы
  5. df.groupby("client_id")["amount"].transform("mean") — среднее своей группы в каждой строке
  6. df.groupby("merchant").filter(lambda g: len(g) >= 40) — HAVING
  7. df.sort_values("x", ascending=False).groupby("category").head(2) — топ-2 в группе
  8. df["amount"].fillna(df.groupby("category")["amount"].transform("median")) — пропуск по группе
05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Чем df.groupby("category")["cashback"].transform("sum") отличается от .sum()?

sum сжимает (6 строк), transform раздаёт (1 800 строк, те же бирки, что у df). Поэтому transform можно класть в колонку.

2. df["x"] = df.groupby("category")["cashback"].sum() — что окажется в колонке x?

Бирки результата — названия категорий, у df — 0…1799. Не совпали ни одной — везде NaN. Нужно transform.

3. Мадина: «Продукты — 29% операций, значит они съедают кэшбэк». Что не так?

Бюджет — это деньги. cb = groupby("category")["cashback"].sum(); cb / cb.sum().

4. Что вернёт df.groupby("merchant").filter(lambda g: len(g) >= 40)?

filter выбрасывает целые группы, а строки хороших групп оставляет как есть. В отличие от SQL HAVING, одной строки на группу нет.

5. Как взять 2 самые крупные операции в каждой категории?

Сначала сортировка, потом head внутри групп = ROW_NUMBER() ≤ 2. Без сортировки head берёт первые по порядку в файле; nlargest — 2 на всю таблицу; max — одно число, без строки.
