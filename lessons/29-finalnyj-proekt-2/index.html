import pandas as pd
import numpy as np

raw = pd.read_csv("uzmarket_orders.csv")
clean = (

02 · Теория

От цифр к рекомендации

Структура отчёта для руководства

Совету директоров не нужны все таблицы. Им нужен ответ на вопрос и доказательства. Хорошая структура — «пирамида»:

  1. Главный вывод одним предложением.
  2. 3 аргумента, каждый с одной-двумя цифрами и, если можно, графиком.
  3. Рекомендации: что делать, сколько это может дать.
  4. Оговорки: что в данных неточно и что нужно проверить.

Каждая задача сегодня — один кирпичик этой пирамиды.

Пример аргумента: одна цифра — один вывод.
cancel = (clean["status"] == "cancelled").groupby(clean["payment"]).mean().mul(100).round(1)
cancel.sort_values(ascending=False)
payment cash 17.9 installment 7.2 card 6.3 Name: status, dtype: float64

Простыми словами: при оплате наличными отменяют 17,9% заказов, картой — 6,3%. Это готовый аргумент: «наличные — главный источник отмен».

Правило отчёта. Рекомендация без цифры — мнение. Рекомендация с цифрой — решение: «перевод половины наличных заказов на карту вернул бы около N млн сум в месяц».
03 · Ловушки

Четыре ловушки финального отчёта

1

Выручка по отменённым

Отменённые заказы не принесли денег. Выручку считай по ok, а долю отмен — по всем заказам clean.

2

Слишком много цифр

Двадцать чисел в письме — никто не запомнит ни одного. В выводе 3–5 главных цифр, остальное — в приложении.

3

Корреляция как причина

«Клиенты с рассрочкой покупают дороже» не значит, что рассрочка заставляет покупать дороже: в рассрочку просто чаще берут электронику. Пиши «связано», а не «приводит».

4

Неполный период

Данные с января по сентябрь. Годовую выручку нельзя получить простым ×12/9 без оговорки: в разных месяцах продажи разные.

Шпаргалка части 2

  1. ok = clean[clean["status"] == "delivered"] — только доставленные
  2. pd.Series({...}) — сводка метрик
  3. ok.groupby("month")["revenue"].sum().pct_change() — динамика и рост
  4. (clean["status"] == "cancelled").groupby(clean["payment"]).mean() — доля отмен по группе
  5. groupby("customer_id")["order_time"].transform("min") — первый заказ клиента
  6. pd.pivot_table(ok, index=..., columns=..., values="revenue", aggfunc="sum") — сводная
  7. ax.set_title("вывод с цифрой") — график-аргумент
04 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Что идёт первым в отчёте для руководства?

Руководитель должен понять главное за 10 секунд, остальное — доказательства.

2. По каким заказам считать долю отмен?

Доля отмен = отменённые / все заказы.

3. Клиенты с рассрочкой покупают дороже. Как это правильно написать?

Связь не доказывает причину: в рассрочку чаще берут дорогие категории.

4. Данные за 9 месяцев. Как оценить годовую выручку?

Любая экстраполяция — с явной оговоркой про сезонность.

5. Сколько главных цифр стоит оставить в письме совету?

3–5 цифр запоминаются, остальное — в приложение.
