Чистка = одна CTE, в которой каждая строка — шаг

В SQL ты бы написал WITH clean AS (SELECT DISTINCT … TRIM(LOWER(…)) …) . В pandas то же самое — цепочка: clean.assign(...).drop(...).astype(...) . Каждая точка — следующий шаг, как следующая строка в SELECT.

Ловушка из SQL. AVG(rating) в SQL пропускает NULL, но не пропускает 0. В pandas так же: mean() пропускает NaN, но 0 считает настоящей оценкой. Поэтому NULLIF(rating, 0) → replace(0, np.nan) — до среднего, а не после.

02 · Теория

Чек-лист чистки: 7 шагов в одном порядке

Простыми словами

Представь, что мама принесла с рынка пакет овощей и просит сварить суп. Ты не кидаешь всё в кастрюлю сразу. Сначала смотришь, что в пакете. Убираешь то, что попало дважды (два одинаковых чека). Моешь (текст: пробелы, большие буквы). Режешь одинаково (числа из текста). Выкидываешь гнилое (невозможные значения). И только потом варишь — считаешь цифры. Перепутаешь порядок — суп испорчен.

  • 1. Посмотреть — shape, info(), head(), value_counts() (урок 1). Что за колонки, какого типа, где грязь.
  • 2. Дубли — duplicated().sum() и drop_duplicates() (урок 5). Дубль — строка, которая полностью повторяет другую. Убираем первыми: иначе все проценты считаются по завышенному числу строк.
  • 3. Текст — str.strip().str.lower(), replace(словарь) (урок 6). Чтобы «ТАШКЕНТ» и «Tashkent» стали одним городом.
  • 4. Числа — pd.to_numeric(..., errors="coerce") (урок 4). Перед ним убираем из текста всё лишнее: пробелы, «сум», «км», меняем запятую на точку.
  • 5. Пропуски и «фальшивые нули» — replace(0, np.nan), where (урок 5). Фальшивый ноль — когда 0 значит «не знаем», а не «ноль». Его меняем на NaN, чтобы среднее не врало.
  • 6. Невозможные значения — маска (x <= 0) | (x > 100) (урок 2). Поездка на 1 250 км по городу — ошибка GPS, а не поездка.
  • 7. Собрать и проверить — assign → drop → astype (уроки 3–4), потом 5 цифр для бизнеса.

История с маленькими числами

Пять поездок. Пассажиры поставили 5, 5, 4, а ещё двое ничего не поставили — в файле у них 0. Excel считает среднее так: (5 + 5 + 4 + 0 + 0) / 5 = 2.8. Звучит ужасно. Честно: (5 + 5 + 4) / 3 = 4.67. Нули — это «не знаем», их нельзя делить вместе с оценками. Если заменить 0 на NaN, mean() сам пропустит пустые места.

r = pd.Series([5, 5, 4, 0, 0])
print(r.mean(), round(r.replace(0, np.nan).mean(), 2))   # 2.8 4.67

У Бахтиёра то же самое, только масштаб больше: 3.08 против настоящих 4.71. Он чуть не урезал бонусы хорошим водителям из-за пустых ячеек.

03 · Теория

Шесть шагов на настоящем файле

Как читать код
  • df.duplicated() — для каждой строки отвечает True, если точно такая же строка уже была выше. .sum() считает True = сколько лишних копий.
  • clean["trip_id"].is_unique — без скобок: это не метод, а свойство («вопрос с ответом»). True — каждый номер встречается один раз.
  • s.replace(0, np.nan) — БЕЗ .str: меняет значение ячейки целиком. Первое в скобках — что ищем, второе — на что меняем. np.nan — «пусто» из библиотеки numpy (поэтому нужен import numpy as np).
  • fare.where(status == "completed") — «оставь значение, где условие True, а в остальных местах поставь NaN». Как CASE WHEN … THEN fare END.
  • (clean.assign(status=status, fare=fare).drop(columns="fare_raw")) — круглые скобки вокруг всей цепочки разрешают переносить строки. assign добавляет/заменяет колонки (имя слева от =, значения справа), drop(columns=...) убирает колонку.
  • .astype({"status": "category"}) — словарь «колонка: тип». category — тип для колонок с несколькими повторяющимися значениями: меньше памяти (урок 4).

Каждый вывод ниже получен реальным запуском pandas 3.0 на файле TezYol. Твои цифры должны совпасть.

print(len(df))
print(round((df["status"] == "cancelled").mean() * 100, 1))

Простыми словами: ровно те числа, что у Бахтиёра. Код правильный, а ответ — нет: данные грязные. 2 050 строк включает дубли, 9.6% считает только «cancelled» маленькими буквами без пробелов, 3.08 делит нули вместе с оценками. Дальше чиним по одному.

2. Дубли: одинаковые строки.
print(df.duplicated().sum())
clean = df.drop_duplicates()
print(clean.shape, clean["trip_id"].is_unique)
50 (2000, 9) True

Простыми словами: 50 поездок экспорт записал дважды. После drop_duplicates осталось 2 000, и каждый trip_id встречается один раз (True). Дальше работаем только с clean.

3. Статус — strip + lower.
status = clean["status"].str.strip().str.lower()
print(status.value_counts())
print(round((status == "cancelled").mean() * 100, 1))
status completed 1724 cancelled 276 Name: count, dtype: int64 13.8

Простыми словами: было 8 «разных» статусов («Cancelled», «CANCELLED», «cancelled » с пробелом…), стало 2. Отмен на самом деле 13.8%, а не 9.6%. Не «лучше рынка», а почти как рынок. Доля — через .mean() * 100 от маски True/False.

4. Цена: число из текста.
direct = pd.to_numeric(clean["fare_raw"], errors="coerce")
fare = pd.to_numeric(clean["fare_raw"].str.replace(r"\D", "", regex=True),
                     errors="coerce")
print(direct.notna().sum(), fare.notna().sum())
print(clean["fare_raw"].head(4).tolist())
1141 1899 ['23000', '14.000', '17 000 сум', '17000']

Простыми словами: если сразу звать to_numeric, он молча превратит в NaN всё с пробелами и «сум» — останется 1 141 цена, а «14.000» станет 14.0 сум. После «выкинуть всё, что не цифра» — 1 899 цен. Остальные 101 — пустые у отменённых поездок.

5. Рейтинг: фальшивый ноль → NaN.
import numpy as np
rating = clean["rating"].replace(0, np.nan)
print(round(clean["rating"].mean(), 2), round(rating.mean(), 2))
print(rating.isna().sum())
3.08 4.71 691

Простыми словами: в 691 поездке оценки нет. Пока они были нулями, среднее было 3.08. Без них — 4.71: водители работают хорошо. Резать бонусы по 3.08 — решение на основе пустых ячеек.

6. Собрать чистую таблицу цепочкой.
trips = (clean
         .assign(status=status, fare=fare, rating=rating)
         .drop(columns="fare_raw")
         .astype({"status": "category"}))
print(trips.shape)
print(df.memory_usage(deep=True).sum(), trips.memory_usage(deep=True).sum())
(2000, 9) 1009817 785641

Простыми словами: добавили чистые status, fare, rating, убрали сырую fare_raw — колонок снова 9. Статус стал category, и таблица уже на 22% легче. В задаче 7 ты почистишь и город, тариф, расстояние — станет ещё меньше.

Правило аналитика. Перед любой цифрой для руководителя задай три вопроса: «нет ли дублей?», «одинаково ли написан текст?», «что значит 0 и пусто в этой колонке?». Ответ «не проверял» = цифра не готова.
04 · Ловушки

Пять ошибок, на которых спотыкается большинство

1

Сначала метрики, потом дубли

share = (df["status"] == "cancelled").mean() # по 2050 строкам с дублями
clean = df.drop_duplicates() # потом всё считаем по clean

Дубли убирают первыми. Иначе каждая доля и каждое среднее чуть-чуть врут.

2

Запятая в числе

pd.to_numeric("3,2 км", errors="coerce") # NaN — молча
pd.to_numeric(s.str.replace(",", ".", regex=False).str.replace(r"[^\d.\-]", "", regex=True), errors="coerce")

pandas понимает только точку как десятичный знак. Запятую меняем на точку, буквы убираем.

3

Ноль вместо «нет данных»

df["rating"].mean() # 3.08 — нули считаются оценками
df["rating"].replace(0, np.nan).mean() # 4.71

Спроси: «0 — это правда ноль?» Рейтинг 0 из 5 невозможен — значит, это пусто.

4

Цена отменённой поездки

fare.median() # 175 нулей у отмен тянут медиану вниз
fare.where(status == "completed").median() # 21500.0

Чек считаем только по выполненным поездкам. Отмена — это не поездка за 0 сум.

5

assign без сохранения

clean.assign(status=status) # результат никуда не сохранён
trips = clean.assign(status=status)

assign не меняет таблицу «на месте», а возвращает новую. Не сохранил в переменную — работы нет.

Шпаргалка урока: чек-лист в 8 строках

  1. df.shape; df.info(); df["col"].value_counts() — посмотреть
  2. df.duplicated().sum(); clean = df.drop_duplicates() — дубли
  3. s.str.strip().str.lower().replace({"tashkent": "ташкент"}) — текст

05 · Самопроверка · 20 XP

Квиз за 3 минуты

1. Почему дубли убирают первым шагом, до всех процентов?

Задвоенная поездка учитывается дважды в каждой цифре. Сначала DISTINCT, потом метрики.

2. Что вернёт pd.to_numeric(pd.Series(["3,2 км"]), errors="coerce")?

coerce не падает, а тихо ставит NaN. Запятую и «км» нужно убрать до to_numeric.

3. Рейтинги: 5, 4, 0, 0 (0 = нет оценки). Какое честное среднее?

replace(0, np.nan) → mean() пропускает NaN: (5 + 4) / 2 = 4.5. С нулями было бы 2.25.

4. Что делает fare.where(status == "completed")?

where = CASE WHEN условие THEN fare END. Длина Series не меняется, отмены становятся NaN.

5. Ты написал clean.assign(status=status) и дальше считаешь по clean. Что не так?

assign не меняет таблицу на месте. Сохраняй: trips = clean.assign(...).
