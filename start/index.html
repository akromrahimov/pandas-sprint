Способ 2 · как на работе

На своём компьютере

Python, VS Code и Jupyter-ноутбуки. Так работают аналитики в компаниях. Файлы с данными скачиваются кнопкой в каждом уроке.

Инструкция ниже ↓

Рабочее место за 20 минут

  1. Установи Python

    Python — язык программирования, на котором работает pandas.

    1. Открой python.org/downloads. Под жёлтой кнопкой найди строку «Or get the standalone installer for Python 3.15.2» и нажми в ней подчёркнутую жёлтую ссылку Python 3.15.2 (если вышла новая версия, номер будет больше — это нормально). Саму жёлтую кнопку «Download Python install manager» не нажимай: она ставит менеджер версий, для курса он не нужен.
    2. Запусти скачанный файл. Важно: внизу первого окна поставь галочку «Add python.exe to PATH», потом нажми Install Now.
    3. Проверь, что всё получилось: открой терминал и выполни команду ниже.
    Что такое терминал. Это окно, куда пишут команды текстом вместо нажатия кнопок. Открыть: нажми Win, напиши «Терминал» и нажми Enter. Команду из тёмного блока ниже копируешь, вставляешь в терминал (Ctrl+V или правой кнопкой мыши) и нажимаешь Enter.
    py --version

    Команда спрашивает «какая у меня версия Python?». Должно появиться Python 3.12, 3.13 или новее. Если пишет «не найдено», перезапусти компьютер и попробуй ещё раз.

  2. Установи VS Code и 2 расширения

    VS Code — бесплатный редактор, в котором удобно писать код. Расширения — это дополнения к нему. Нужны только два, оба от Microsoft:

    Pythonчтобы VS Code понимал язык Python и подсвечивал ошибки
    Jupyterчтобы писать код по кусочкам и сразу видеть результат, как на этом сайте
    1. Открой code.visualstudio.com и нажми синюю кнопку Download for Windows справа вверху. Запусти скачанный файл: прими соглашение (I accept), нажимай Next, потом Install и Finish. Если VS Code у тебя уже есть, этот пункт пропусти.
    2. Слева нажми на значок из четырёх квадратиков Extensions (или Ctrl+Shift+X).
    3. В поиске напиши Python, выбери первое расширение с подписью Microsoft и нажми Install.
    4. То же самое для Jupyter.
    Или поставь оба расширения одной командой

    Скопируй и выполни в терминале. Команда делает то же, что кнопка Install: code — это VS Code, --install-extension — «установи расширение», дальше его точное имя.

    code --install-extension ms-python.python
code --install-extension ms-toolsai.jupyter

    Если пишет, что code не найдена, закрой и снова открой терминал после установки VS Code.

  3. Установи библиотеки одной командой

    Библиотеки — это готовые наборы инструментов для Python. pip — программа, которая их скачивает. Скопируй команду целиком, вставь в терминал и нажми Enter:

    py -m pip install pandas matplotlib openpyxl ipykernel
    py -m pip install
    «Python, установи эти библиотеки» — именно в тот Python, который ты поставил на шаге 1
    pandas
    таблицы — главный инструмент курса
    matplotlib
    графики (урок 20 и проекты)
    openpyxl
    чтение и запись Excel-файлов (урок 25)
    ipykernel
    связь между VS Code и Python, без неё ноутбуки не запустятся

    Установка займёт 1–3 минуты, в конце появится Successfully installed …. Красные строки с WARNING про pip можно не читать — это не ошибка.

  4. Создай папку курса и первый ноутбук

    Ноутбук — файл, где код пишется по кусочкам (ячейкам), а результат виден сразу под каждой ячейкой.

    1. Создай обычную папку, например Документы → pandas-sprint, как любую другую папку на компьютере.
    2. Скачай файл с данными кнопкой в уроке 1 и положи его в эту папку.
    3. В VS Code: File → Open Folder → выбери папку pandas-sprint.
    4. File → New File → Jupyter Notebook. Сохрани как day01.ipynb.
    5. Справа сверху нажми Select Kernel → Python Environments. В списке выбери строку Python 3.15.2 (или ту версию, что ставил на шаге 1), у которой путь заканчивается на Python315\python.exe. Строки с .venv не выбирай.
    6. Напиши в ячейке import pandas as pd и нажми Shift+Enter. Если VS Code спросит «Running cells requires the ipykernel package. Install?» — нажми Install и подожди. Под ячейкой появилась зелёная галочка и нет красного текста — всё готово!
    Ошибка «No module named 'pandas'»? Значит, ноутбук подключён не к тому Python. Нажми справа сверху на название Python → Select Another Kernel → Python Environments и выбери другой. Если в списке несколько .venv, выбери обычный Python 3.x без .venv: библиотеки ставились именно в него.

  5. Знаешь SQL? Подсказка для тебя

    SQL для курса не нужен. Но если ты с ним работал, в каждом уроке есть кнопка SQL → pandas (слева в оглавлении и вверху урока). Она открывает таблицу-переводчик: как то же самое пишется на SQL и на pandas.

  6. Не получается? Есть вариант без установки

    Google Colab — ноутбуки прямо в браузере, нужен только Google-аккаунт. Файл с данными загружается через значок папки слева. В первой ячейке выполни команду ниже, чтобы обновить pandas, затем меню Среда выполнения → Перезапустить сеанс.

    !pip install -U "pandas>=3.0"
